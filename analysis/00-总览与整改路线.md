## 一、一句话结论

这个项目的「不直观、不清晰、不够详细」**不是三个独立问题，而是同一个根因的三层表现**：

> **它把"教 Hudi"压缩成了"播报一次文件变化"。**
> 80 个主题每个只有 4 步、每步 1 句（平均 20.8 字符），既没有目标/前置/结论/自检，也没有术语定义；
> 真正详细的旧界面（文件树、Timeline 表、记录表、测验，约 5900 行）全部挂在**没有路由的死页面**上；
> 学生实际能看到的只剩一张等比缩放的 SVG + 一行 13px 的说明。

## 二、三个根因（跨三份报告的共识）

### 根因 A · 内容层：教学结构整体缺失

| 指标 | 实测 | 影响 |
|---|---|---|
| 有「目标 / 前置 / 结论 / 自检」的主题 | **0 / 80** | 学生不知道"看这个有什么用、看完该会什么" |
| 全站解释"为什么"的句子 | **3 / 315 步**（0.95%） | 只记画面，记不住机制 |
| 每主题全部讲解字数 | **53 汉字**（≈84 字符） | 信息量约等于一条微博 |
| ≤12 字且无因果词的步骤 | **145 / 315（46%）** | 最极端：`先生成计划。`（B04#4） |
| 24 个核心术语在旁白里的定义数 | **0** | File Group / File Slice 首课（B01#3/#4）即裸用；Checkpoint 全站用 9 次无定义；Compaction 要到第 41 个主题后才解释 |
| 免责/边界话术占比 | **57 / 315 步（18%）**、37/78 主题 | 「本页不模拟…」「待验证」挤掉了「为什么」 |
| 零操作或仅 1 次操作的主题 | **20 / 78（26%）** | 动画里"什么都没发生"，建立不了因果直觉 |
| 目录卡片展示 summary 的数量 | **0 / 80** | 写好的一句话解释只藏在抽屉里 |
| 44 个 SQL/命令模板中在动画页从未出现的 | **32** | 学完 S07 Archive 仍看不到 `RUN ARCHIVELOG`；S08 Rollback 没有任何回滚命令 |

**证据**：`src/experiments/visual/lessons.ts`（315 步）、`src/experiments/visual/types.ts:4-15`（`VisualLesson` 无教学字段）、
`src/experiments/index.ts:16`（全站只注册 1 个 `ExperimentDefinition`）、`src/views/ExperimentView.vue:31,919`（`QuizPanel` 唯一使用处，而该页无路由）。

### 根因 B · 界面层：细节被塞进抽屉，画布是"缩放到底"的 SVG

| 指标 | 桌面 1440×900 | 移动 390×844 |

| 首屏画布 : 讲解 面积比 | **420px : 70px ≈ 6 : 1**（讲解 13px 字号） | — |
| 画布缩放 | 0.988，但对象只占画布宽 **12.7%** | **0.337** → 10px 字渲染成 **3.4px**、12px 成 4.0px，内容只占画布高 42% |
| 图例 | **12 个动画页只有 B02 有**（179×16，10px 字号） | — |
| 术语定义获取成本 | "MOR 的 Log 文件是什么" 需 **4–5 次点击、跨 2 个页面，仍拿不到定义** | — |

**证据**：`src/components/visual/LessonCanvas.vue:20`（`viewBox="0 0 1080 425"`）、`src/components/visual/FileGlyph.vue:20`（10px 文本）、
`src/views/LessonView.vue:130-136`（Timeline 用 `JSON.stringify` 原文、源码透视渲染字面 `\n`）、`src/views/VisualLabView.vue:86`（唯一图例）。

### 根因 C · 结构层：两代产品并存 + 页面之间断链

- **详细的旧版是死代码**：`FileTreeView.vue`(684) / `TimelineView.vue`(484) / `RecordTable.vue`(344) / `BucketView.vue`(531) / `QuizPanel.vue`(211) / `ExperimentView.vue`(860) / `DashboardView.vue`(261) 全部没有路由（`src/app/router/index.ts:20-55`），约 **5900 行**。只有 B02 注册了 `ExperimentDefinition`。
- **进度永远为空**：80 个动画主题从不写 `lab.progress`（`LessonView.vue` 只用了 `lab.darkMode`）。实测：完整看完 B05 后 `localStorage['hudi-lab-progress']` 仍为 `null`，`/progress` 显示"暂无数据"。且 `/progress`、`/evidence` 在视觉页**零入口**（只在旧 `MainLayout` 左栏里）。
- **这两页还是另一套 UI**：旧 MainLayout + Element Plus 壳，标题「Hudi Lab」而非「Hudi Visual Lab」，移动端横向溢出 **494 > 390**。
- **「基础模式 / 工程师模式」是假开关**：切换后 DOM 元素 **110 → 110**，`innerHTML` 仅 +18 字符（两处文案），B02 页多一个「模拟失败」按钮。
- **两套渲染器**：`/experiment/B02|B03` 走 `VisualLabView`（无章节条、抽屉 6 tab），其余 78 个走 `LessonView`（5 章节、抽屉 7 tab）——同一入口两套结构。
- **搜索形同虚设**：`AnimatedCatalogView.vue:8` 只匹配 `id + title`，搜「文件组」「日志」**0 命中**（但正文里写的是 File Group / Log File）。
- **键盘有 bug**：Enter 打开图元详情后，事件冒泡触发详情框自身的关闭动作，抽屉一闪而过；焦点陷阱 16 次 Tab 中漏出 2 次。

## 四、整改路线（按"投入产出比"排序，不按技术难度）

### 第一批 · 1 天，零结构改动，直接消掉"不直观"体感

1. **页头加「本课目标 + 3 张术语卡」**（一句话定义、可点开）—— 改 `LessonView.vue` 页头区，数据先从 `catalog.summary/note` 自动生成。
2. **画布加常驻图例**（Base File / Log File / 旧版本 / 本次新增），字号 ≥12px——改 `LessonCanvas.vue`。
3. **旁白改三段式**并加长到 45–90 字，先改 8 个代表主题（B01 / B04 / B05 / I03 / Q02 / S01 / S04 / E01）。
4. **字号与对比度**：正文 ≥14px、辅助文字 ≥12px，删掉全部 9px；浅色 `--vl-muted` 提到 ≥4.5:1（建议 `#5f6f66`）。
5. **目录卡片加 1 行 summary + 难度 + 时长**；搜索扩展到 `id + title + summary + 术语别名`。
6. **移动端画布**：≤550px 走 HTML 单步卡片（或 snap 滑动 + 圆点章节），并把 22 个小触控目标放大到 ≥44px。

### 第二批 · 1–2 周，把"详细"搬回界面（复用死代码，不新写）

7. **复活详情层**：页内 dock（URL 可寻址 `?tab=timeline`），把 `TimelineView / FileTreeView / RecordTable / SqlBlock / QuizPanel` 接上，替换现有 JSON dump。
8. **建立课程状态层** `src/app/stores/lesson.ts`：`visited / watched / mastered / lastSeen / 播放位置`，主题页挂载与完成时写入；`/progress` 并入视觉体系并在导航常驻。
9. **学习路径 + 术语表 + 难度/前置标签**（3 条纵向路线；术语表 24 词，标注首次出现主题）。
10. **统一 80 主题渲染入口**：取消 `/experiment/B02|B03` 特例路由，B02 双泳道下沉为 `LessonCanvas` 的 `kind: 'compare'`。

### 第三批 · 2–3 周，内容工业化

11. **80 主题补齐 `objective / prerequisites / takeaway / quiz`**（`02-content-audit.md` 第三节已有 B01/I03/S04 完整范例可直接落库）。
12. **术语首现行内定义 + 免责话术分级披露**。
13. **主题级 SQL 模板映射**（补齐 Archive / TTL / Rollback / Clustering / Bulk Insert 等 32 条命令）。
14. **修 20 个空转主题**，或明确改写 summary 承诺。
15. **代码可读化**（先拆 CSS 与 `LessonView`，再动其他）：`LessonView.vue` ≤80 行、模板单行 ≤120 字符、导航只留 1 份实现。

> 建议顺序：**样式/文案单一来源 → 拆 LessonView → 状态层 → 详情层 → 统一入口**（与 `03-ia-code-audit.md` 的重构前置项一致），每步用 `npm run typecheck` + `npm test` + 实测脚本做前后对比。
