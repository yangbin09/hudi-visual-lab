## 五、还没做的（第三批剩余 + 两个已知缺口）

1. **20 个空转主题**（T05/T06/T08/W07/F04/F07/F08/E01/E10/A03/A04 等 11 个零操作主题）仍缺一次可观察的状态变化——需要逐题设计，量最大。
2. **前置依赖 DAG**：目前「先修」是文本提示，没有「本主题用到 X，见 B04」的自动检测。
3. **B02 / B03 仍是独立渲染器**（`VisualLabView`）：已补齐目标条、术语栏、图例、进度、自测、边界，与其它主题页同标准，但**没有接入页内 dock**（它自己保留 SQL/HDFS/Timeline 抽屉）。彻底统一需要把双泳道画布下沉为 `LessonCanvas` 的 `compare` 场景。
4. **术语表 30 词 vs 24 核心词**：多出 File ID、DeltaCommit 等服务词；核心词定义已齐，剩余词的 `firstTopic` 可再校准。
5. `npm run dev` 在 Windows 上偶发因文件监听 `EBUSY` 崩溃，已在 `vite.config.ts` 打开 `server.watch.usePolling` 规避。
